# Client Onboarding SOP — selling the AI voice agent

The delivery playbook so each new client is live in ~1 week at healthy margin.

## Sales → onboarding flow
1. **Free demo call** — let the prospect talk to a live agent (use your own receptionist number). This closes deals.
2. **Pick a tier** (Reception ₹6k / Growth ₹16k / Scale ₹40k) + collect the **setup fee 100% upfront**.
3. **Intake form** (Jotform) — capture the fields below.
4. **Build** — clone an agent prompt, swap business name + scripts, set the voice, connect their number/CRM. Reuse your templates (near-zero repeat labour).
5. **Pilot 3–5 days** on real calls, tune Hinglish.
6. **Go live** + add the client to the billing dashboard.
7. **Day-14 report**, then **monthly report** (calls, leads, recovered ₹). Day-90: offer annual prepay (2 months free).

## Intake form fields
Business name · contact + phone · use-cases (receptionist / reminders / lead calling / collections) · languages · their +91 number (new or port) · CRM (or use Zoho) · working hours · sample FAQs · **consent source** for any outbound list · GSTIN (for their invoice) · authorised signatory (for their DLT PE).

## Contract clauses to include (compliance push-down)
- **Client is the sender / Principal Entity.** Client warrants it holds valid consent for all contacted numbers and is (or will be) DLT-registered.
- **Lawful use.** Client will not use the service for promotional calls to non-consented / DND numbers; promotional calls use a 140-series number.
- **Data roles.** Client = Data Fiduciary; TCC = Data Processor. Data stays in India; retention per policy; deletion on request.
- **Recording.** Calls disclose recording; client owns customer data and indemnifies TCC for content it supplies.
- **Liability.** TCC provides setup + platform ops; regulatory liability for the client's own campaigns rests with the client.
- **Term.** 3-month minimum, then monthly; setup non-refundable; overage billed monthly in arrears from call logs.
